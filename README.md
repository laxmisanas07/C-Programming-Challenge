## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/laxmisanas07/C-Programming-Challenge.git
```

### 2. Navigate to the Project

```bash
cd C-Programming-Challenge
```

### 3. Compile a C Program

Using GCC:

```bash
gcc filename.c -o output
```

### 4. Run the Program

**Linux / macOS:**

```bash
./output
```

**Windows:**

```bash
output.exe
```

## 📝 Sample C Program

Here is a simple Hello World program:

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!\n");

    return 0;
}
```

**Output:**

```text
Hello, World!
```
